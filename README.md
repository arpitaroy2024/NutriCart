# NutriCart

NutriCart is an Android application designed to help users plan
groceries and make more informed nutrition decisions based on their
personal preferences and health-related information.

## 🚧 Development Status

> This project is currently under active development.

### Completed

- [x] Phase 0 — Project Foundation

### In Progress

- [ ] Phase 1 — Design System & Reusable Components
- [ ] Phase 2 — Local Storage
- [ ] Phase 3 — Authentication & Onboarding

- [ ] Phase 5 — Grocery Generation
- [ ] Phase 6 — Grocery List Editing
- [ ] Phase 7 — Nutrition Analysis
- [ ] Phase 8 — Allergy & Health Alerts

- Android SDK

- Grocery list management
